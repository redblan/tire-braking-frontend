# BrakePath — фронтенд (React)

SPA сервиса «Расчёт тормозного пути»: плитка услуг с фильтром и пагинацией, лента с 3D моделью, «Подробнее», добавление услуги и вход. Услуга — условия торможения: коэффициент сцепления шины `mu_tire` и покрытия `mu_surface`.

Данные берутся из веб-сервиса на Go (`tire-braking-backend`). Если бэкенд недоступен, гость видит mock-услуги из `src/modules/mock.ts`.

Стек: React, TypeScript, Vite, React Router, React-Bootstrap, Redux Toolkit (redux-thunk), Axios, Three.js, Tauri 2, transformers.js (SigLIP). `React Context` не используется.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Связь с бэкендом

- **Прокси Vite** (`vite.config.ts`): `/api` и `/static` → веб-сервис `http://localhost:8080`, `/brakes` → S3 (Minio) `http://localhost:9000`. Браузер обращается только к адресу фронтенда, ограничения CORS нет.
- **Кодогенерация**: `src/api/Api.ts` сгенерирован из swagger бэкенда (Axios):

  ```bash
  npx swagger-typescript-api generate -p ../tire-braking-backend/docs/swagger.json -o ./src/api -n Api.ts --axios
  ```

- **Redux Toolkit** (`src/store`): запросы домена услуг выполняются в `thunk` через сгенерированный клиент.

| Слайс | Что хранит | Thunk |
|---|---|---|
| `tireConditions` | страница плитки, фильтр `grip`, `currentPage`, `totalPages` | `fetchTireConditions`, `deleteTireCondition` |
| `feed` | услуга ленты | `fetchFeedItem`, `pollFeedItem` (Short Polling), `likeTireCondition` |
| `draft` | черновик на странице добавления | `fetchDraftTireCondition`, `createTireCondition`, `publishTireCondition` |
| `search` | кэш текстовых эмбеддингов: `id` услуги → вектор её описания на английском | нет: эмбеддинги считает Web Worker |
| `auth` | состояние после авторизации (`isAuthenticated`, `username`, `token`) | нет: вход и выход — только `axios`, состояние передаётся вручную |

JWT после входа лежит в `localStorage` (ключ `access_token`). После F5 Redux возвращается в состояние гостя, токен в `localStorage` остаётся.

Пока идёт запрос, поверх страницы показывается анимация загрузки, закрывающая кнопки.

## Нижняя панель

Четыре пункта: **Лента**, **Добавление**, **Плитка**, **Вход**. После авторизации вместо «Вход» — **Выход**; при выходе фильтр плитки сбрасывается.

## Страницы

### Плитка — `/`

- Ползунок «Мин. коэффициент сцепления» — минимальное значение `mu_tire` от 0 до 1.20 с шагом 0.05; на нуле фильтра нет.
- Кнопка «Применить фильтр» — фильтр сохраняется в Redux и уходит в запрос `GET /api/tire-conditions?grip=&page=&limit=10`; показ начинается с первой страницы.
- «Найдено услуг» — `total` из ответа бэкенда.
- Карточка услуги — изображение (если пусто или недоступно, `DefaultImage.jpg`), название, «шина» и «покрытие»; клик открывает «Подробнее». У своих услуг (`is_owner = 1`) есть кнопка «Удалить».
- «Поиск по изображению (на этой странице)» — выбор файла изображения, поиск похожих карточек среди услуг текущей страницы (см. «Поиск по изображению»); «Сброс» возвращает обычный список.
- Пагинация — предыдущая, первая, номера рядом с текущей, последняя, следующая; номер страницы хранится в Redux.

### Подробнее — `/detail/:id`

- Изображение, название, описание, краткое описание на английском, `mu_tire` и `mu_surface`.
- Кнопка «Открыть в ленте» — переход на `/feed/:id` этой услуги.

### Лента — `/feed`, `/feed/:id`, `/feed/:id?next=true`

- `/feed` — первая услуга ленты сессии (лента — 100 случайных услуг, хранится в Redis на бэкенде), `/feed/:id` — услуга `id`, `/feed/:id?next=true` — следующая после `id`.
- Вместо видео — 3D модель услуги (`model_url`, `.glb`) в `Three.js`, повёрнутая на углы `angle_x` и `angle_y`. Если модели нет или файл недоступен — `DefaultModel.glb` из проекта.
- Сверху — порядковый номер услуги в ленте и текущие углы.
- **Short Polling**: раз в 2 секунды вызывается метод ленты по `id` услуги на экране. Запрос с `next=true` запускает асинхронный сервис, через 5–10 секунд углы в БД меняются, и модель доворачивается в новое положение.
- Кнопка «Далее» — переход на `/feed/:id?next=true`.
- Кнопка «♥» (только после входа) — поставить или снять лайк.

### Добавление — `/add`

Только для авторизованного пользователя (гость видит кнопку «Войти»).

- Шаг 1: фото, 3D модель (`.glb`), название, кнопка «Далее» — создаётся черновик, файлы уходят в Minio.
- Шаг 2 (черновик уже есть): фото и 3D модель черновика, название (только чтение), «Коэфф. сцепления шины», «Коэфф. сцепления покрытия», «Описание», «Краткое описание на английском (50–100 символов)», кнопка «Опубликовать».

### Вход — `/login`

- Поля «Логин» и «Пароль», кнопка «Войти» — `POST /api/auth`.

## Поиск по изображению

Модель одна — SigLIP (`Xenova/siglip-base-patch16-224`, `transformers.js`, квантование `q8`), она переводит и изображение, и текст в векторы одного пространства (768 чисел). Изображение из запроса сравнивается с **текстами** карточек — краткими описаниями на английском `description_en`.

1. Пользователь выбирает файл изображения на странице «Плитка».
2. Web Worker `src/workers/search.worker.ts` загружает модель (один раз) и считает текстовые эмбеддинги описаний карточек текущей страницы, для которых эмбеддинга ещё нет. Результат кэшируется в Redux (`search.textEmbeddings`) — описание считается один раз, при первом запросе.
3. Эмбеддинг изображения считается при каждом запросе.
4. `src/hooks/useImageSearch.ts`: косинусное сходство изображения с каждой карточкой страницы (`src/modules/math.ts`), сходство приводится к шкале 0–1 среди карточек страницы (1 — самая похожая), остаются карточки не ниже порога, не больше TopK, по убыванию.

Порог и TopK — `SEARCH_THRESHOLD` и `SEARCH_TOP_K` в `src/config.ts`. Поиск ограничен карточками текущей страницы пагинации.

## Нативное приложение (Tauri)

То же React-приложение в окне Tauri (`src-tauri`) — интерфейс гостя из двух страниц: список услуг (фильтр, пагинация, поиск по изображению) и «Подробнее». Ленты, добавления и входа в нём нет (`IS_TAURI` в `src/config.ts`).

- Оформление окна — `src/Native.css` (класс `native` на `<html>`): раскладка на всё окно, сетка карточек, шапка с адресом веб-сервиса, светлая и тёмная тема по настройке системы. Веб-версия остаётся мобильной колонкой.
- Собранное приложение не имеет прокси Vite, поэтому обращается к веб-сервису напрямую по IP компьютера в локальной сети, не `localhost`: `BACKEND_IP` в `src/config.ts` → `http://<IP>:8080` (API) и `http://<IP>:9000` (Minio).
- На бэкенде для этого включён CORS.
- `src-tauri/Info.plist` разрешает приложению незашифрованные (`http`) запросы в macOS.

```bash
bash run_tauri.sh     # подставляет текущий IP (ipconfig getifaddr en0) в src/config.ts и собирает приложение
open src-tauri/target/release/bundle/macos/BrakePath.app
```

Вручную: `npm run tauri build` (сборка), `npm run tauri dev` (режим разработки).

Порт приложения при обращении к бэкенду: `sudo tcpdump -i any -n tcp port 8080` — в строках запросов `IP <IP>.<порт приложения> > <IP>.8080`.
