# BrakePath — фронтенд (React)

SPA сервиса «Расчёт тормозного пути» для гостя: плитка услуг с фильтром, лента и страница «Подробнее». Услуга — условия торможения: коэффициент сцепления шины `mu_tire` и покрытия `mu_surface`. Данные берутся только из mock-объектов `src/modules/mock.ts`, бэкенд не используется.

Стек: React, TypeScript, Vite, React Router, React-Bootstrap. Redux и `React Context` не используются.

```bash
npm install
npm run dev      # http://localhost:3000
```

## Нижняя панель

Четыре пункта: **Лента**, **Добавление**, **Плитка**, **Вход**. Доступны «Лента» (открывает первую услугу списка) и «Плитка», «Добавление» и «Вход» неактивны.

## Страницы

### Плитка — `/`

- Поле «Сцепление шины от» — минимальное значение `mu_tire` (`0.8` или `0,8`).
- Кнопка «Фильтр» — оставляет услуги с `mu_tire` не меньше введённого значения; пустое поле показывает все услуги.
- Карточка услуги — изображение (если пусто, `DefaultImage.jpg`), название, «шина» и «покрытие»; клик открывает «Подробнее».
- Сообщение «К сожалению, пока ничего не найдено :(» — если фильтру не соответствует ни одна услуга.

### Подробнее — `/detail/:id`

- Изображение (если пусто, `DefaultImage.jpg`), название, описание, `mu_tire` и `mu_surface`.
- Кнопка «Открыть в ленте» — переход на `/feed/:id` этой услуги.

### Лента — `/feed/:id`

- Видео на весь экран (если пусто, `DefaultVideo.webm`), название, описание, теги «шина» и «покрытие».
- Кнопка «Далее» — следующая услуга по порядку в списке плитки; на последней ничего не делает.
